# Logo assets

SVG and 512 x 512 transparent PNG artwork from the private `libtmux/assets`
kit, revision `4b86a9d9158d7c6d52cd635d59c92a04b48b960f`
(`assets/elixir/library`).

Library marks use the tiled libtmux base with its cog. Elixir's primary tile
is `#8847B9` from the pinned
[GitHub Linguist palette](https://github.com/github-linguist/linguist/blob/538da05f034fa5c83bd81df128d144e208898da3/lib/linguist/languages.yml),
with the family's OKLab shade adjustments on the upper and lower tiles. The
source libtmux and tmuxp paths belong to the project owner.

- `logo.svg` (`5885` bytes): SHA-256
  `26558c9536840d516aa6d19d0ec4a22862b80d70cf54a00840af23153c25942a`
- `logo.png` (`16031` bytes, from `logo-512.png`): SHA-256
  `6163616564ac8157296f2f995a341a8832e95475c8fe6cd3fd6f70c48747f368`

ExDoc embeds `logo.svg` and copies `assets/` into the rendered site. Shared
browser icons and social preview cards live in `libtmux/docs` under
`site/public/brand/elixir/`.
